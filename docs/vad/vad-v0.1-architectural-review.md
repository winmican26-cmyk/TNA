# VAD Engine v0.1 Architectural Review Memo

This memo is an evidence-based audit of the VAD Engine v0.1 milestone. It does not modify runtime code, tests, schemas, architecture, or behavior. It only maps the original requirement set to the actual implementation and fresh verification evidence.

## 1. Test-count provenance and baseline reconciliation

### Gate baseline verification

The accepted Gate v0.3 baseline is confirmed as follows:

- tag: `tna-gate-v0.3`
- annotated tag object SHA: `b30c1a93c8fc8b70dde96f8b76e3e085e1a10dce`
- peeled commit SHA: `718a801ff9e3085faf4e69d1dbf924a1b6e6c047`
- current HEAD: `718a801ff9e3085faf4e69d1dbf924a1b6e6c047`
- VAD changes are uncommitted: `git status --short --branch` shows only newly added VAD files under [apps/vad-engine](../../apps/vad-engine), [packages](../../packages), [tests/vad](../../tests/vad), and [docs/vad](../../docs/vad)

The accepted Gate baseline had 110 tests. The VAD milestone adds 7 new logical tests in [tests/vad/vad-engine.test.ts](../../tests/vad/vad-engine.test.ts).

The Node test runner reported a total of 117 tests; this reconciles exactly as:

- Gate regression tests: 110
- VAD tests: 7
- Total: 117

Proof: `110 + 7 = 117`

The VAD test file contains 7 `test(...)` invocations, corresponding to the new VAD regression cases:

1. `atom spec rejects unsupported version`
2. `canonical spec hash ignores insertion order`
3. `resource manifest detects undeclared file changes`
4. `validation gate accepts deterministic evidence and rejects false self-claims`
5. `retry context excludes prior producer conversation history`
6. `verifier rejects invented criteria and missing criteria`
7. `accepted demo atom completes the VAD flow`

Fresh verification output from `npm run check` reported:

- 117 total tests
- 117 pass
- 0 fail

Therefore the original 110 Gate tests are still present and passing, and the 7 VAD tests are added deterministically to the same suite.
